Repositorio geral para guardar materiais, exercicios e projetos desenvolvidos durante a faculdade. Ele funciona como um arquivo central de estudos, reunindo conteudos de HTML, CSS, JavaScript e atividades academicas.

## Conteudo

- Aulas e exercicios de desenvolvimento web.
- Projetos academicos organizados por pasta.
- Materiais de apoio e revisao.
- Exemplos de logica e frontend.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Como visualizar

Acesse pelo GitHub Pages:

https://matheusgdqueiroz-del.github.io/tudo-da-faculdade/

Alguns projetos estao em subpastas; abra o arquivo `index.html` correspondente para visualizar cada atividade.
