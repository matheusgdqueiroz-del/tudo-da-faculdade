Repositório geral para guardar materiais, exercícios e projetos desenvolvidos durante a faculdade. Ele funciona como um arquivo central de estudos, reunindo conteúdos de HTML, CSS, JavaScript e atividades acadêmicas.

## Conteúdo

- Aulas e exercícios de desenvolvimento web.
- Projetos acadêmicos organizados por pasta.
- Materiais de apoio e revisão.
- Exemplos de lógica e frontend.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Como visualizar

Acesse pelo GitHub Pages:

https://matheusgdqueiroz-del.github.io/tudo-da-faculdade/

Alguns projetos estão em subpastas; abra o arquivo `index.html` correspondente para visualizar cada atividade.
